## Big Course Promise

By the end of this course, students should be able to:

1. Write small Python programs that solve clear problems.
2. Use variables, selection, loops, functions, strings, lists, dictionaries, and files.
3. Read, trace, test, debug, and improve Python code.
4. Break problems into smaller steps and explain their reasoning.
5. Use programming tools, documentation, classmates, and AI tools responsibly as part of a learning workflow.
