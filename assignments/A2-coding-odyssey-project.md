# Reusable assignment: Coding Odyssey / Choose Your Own Adventure

**Template based on the recurring staged creative project.**

Build a project of your choice that applies the current concepts. At each checkpoint, submit a working version, explain what changed, and demonstrate it. The final version should be playable/usable, clear enough for another person to try, and accompanied by a brief reflection or report.

Historically this appears as CYOAG or Coding Odyssey 1–3 plus a final. Rubrics vary, but creativity, clarity, effort, playability, and presentation recur; language/IDE/engine, sprites, and extra features sometimes receive bonus points.

## Fall 2026 checkpoint structure (Decision, 2026-07-22)

Four checkpoints plus the final portfolio submission, one graded stage
earlier than the historical three-checkpoint pattern. See
`reports/007_coding_odyssey_baby_project_checkpoint.md`.

1. **Checkpoint 1 — Week 6 — "baby project" / dry run.** A small, complete,
   low-stakes project using only what's been taught through loops (Weeks
   1–6): pick a tiny idea, build it, submit a working version, explain it
   in a sentence or two, demo it. The point isn't the project itself — it's
   rehearsing the checkpoint mechanics (submit, explain, demonstrate)
   before the real project ramps up, so Checkpoint 2's first real
   submission doesn't also carry first-time submission-mechanics overhead.
   Scope this small enough that scope/idea selection isn't itself a
   barrier — a few dozen lines is a completely acceptable "baby project."
2. **Checkpoint 2 — Week 9 — first real pass on the actual Coding
   Odyssey project.** Now genuinely a second check-in, not a first one, so
   it can go deeper: real project idea, meaningfully more code, closer to
   the eventual scope. Lands in Fall Break's shortened week, same as
   before, but the first-time overhead Checkpoint 1 used to absorb is
   already spent.
3. **Checkpoint 3 — Week 14 — expanded pass**, paired with GitHub/tools
   work and a show-and-tell reflection.
4. **Checkpoint 4 — Week 16 — final creative-project pass**, paired with
   full show-and-tell and the final-reflection kickoff.

Final Coding Odyssey portfolio submission remains Week 17 (finals week),
unchanged.
