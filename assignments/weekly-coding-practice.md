# Reusable assignment: weekly coding practice

**Template based on recurring Chapter 1–9 assignments; adapt the chapter and problem set.**

Complete three problems from the current chapter (or propose a comparable problem). Submit code, representative output, and a short explanation/report. Demonstrate the work in discussion or show-and-tell when scheduled.

## Historical grading pattern

The repeated structure is effort plus working solutions: roughly 25 points for effort, then 50/75/100 for one/two/three working programs, with optional improvement bonuses. Earlier offerings use fixed ZyBooks labs; later offerings permit substitutions, Coding Quests, or pair-programming versions.
