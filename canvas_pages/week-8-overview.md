# Week 8 Overview: Strings Are Objects

## Week at a glance

This week's idea: a string is an object. It has a value and it has behaviors you
can ask for with `object.method()`. You do not write your own classes yet.

Monday: AI I Lens 8, Reason. When do we need deeper analysis instead of quick
generation? Choosing between indexing, slicing, and searching asks for the same
reasoning-before-acting.

Wednesday and Friday: Professional Minds Week 8, craftsmanship. What does
professional software craftsmanship look like? Wednesday uses *The Pragmatic
Programmer*; Friday uses *Clean Code* and a show-and-tell of a string-processing
program with clean, readable formatting.

## What you learn

- Create strings, join them, and build them with f-strings.
- Index and slice strings to pull out parts of their text.
- Search and transform text with string methods.
- Read `object.method()` and explain the dot and the parentheses.
- Explain that strings are immutable, so a transformation must be saved.
- Use `type()`, `dir()`, and `help()` to investigate an unfamiliar object.
