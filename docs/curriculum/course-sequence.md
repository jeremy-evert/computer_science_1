# Computer Science 1: historical course sequence

This map is a reusable base derived from the Canvas archive (spring 2021–spring 2026). It is organized by learning arc, not semester copy. Chapter numbers follow the recurring ZyBooks/Python sequence; exact weeks and point values varied.

1. **Launch and learning habits** — welcome/introduction, environment setup, attendance, show-and-tell, and (in later offerings) planning for graduation and a career.
2. **Python foundations** — Chapter 1: printing and input; Chapter 2: variables and expressions; Chapter 3: types and formatted output.
3. **Control flow** — Chapter 4: branching; Chapter 5: loops.
4. **Decomposition and text** — Chapter 6: functions; Chapter 7: strings.
5. **Applied project checkpoints** — Coding Odyssey / Choose Your Own Adventure Game 1, 2, and 3, each revisiting the available concepts.
6. **Object-oriented programming** — Chapter 9, commonly split into Round 1 and Round 2: classes, objects, methods, and modules.
7. **Collections** — Chapter 8: lists and dictionaries (the chapter order was usually placed after Chapter 9).
8. **Tools and authentic application** — GitHub/source control, pair programming, AI-aware coding practice, and a final creative project (usually Coding Odyssey/CYOAG).
9. **Professional reflection** — unofficial transcript, advisor/progress check, degree plan, resume, dream-job research, gap analysis, LinkedIn/GitHub, and end-of-semester reflection. This strand became prominent in 2023–26.

The archive does not support treating this as a rigid calendar. Spring 2021 used four modules and chapter exams; spring 2022 covered fewer chapters; fall 2025 doubled some work with Coding Quests and paired versions; spring 2026 introduced a week-by-week page-based launch. Preserve the sequence, but allow the project/tool/professional strands to flex around the semester.
