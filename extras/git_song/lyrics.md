# Git Ain't GitHub (The Friday Night Push)

**Original novelty-country teaching song · rough v0 · October 9, 2026**

A deliberately corny 2/4 country storytelling tune about local Git history, the staging area, commits, and the GitHub remote. It borrows the *general energy* of old-fashioned comic country storytelling and novelty parody, **not any copyrighted song's tune or lyrics**. The first proof audio has a robotic talk-sung guide vocal because the goal is to hear something today, not wait for a trained singing model.

## Spoken count-in
One, two, three! That squirrel says I forgot the push!

## Verse 1
Well, I changed three files on a Friday night,  
Had a bug in the barn, and my terminal bright,  
I told my buddy, "Check GitHub! I fixed that code!"  
He said, "That page still shows last week's load!"

## Chorus
Git add to the stage, git commit makes it stay,  
Push it to the remote if your friends should see today,  
Git remembers local history, GitHub hosts the show,  
If you never push your commits, your friends will never know!

## Verse 2
I ran git status, saw the files I'd changed,  
Added just the ones I wanted, kept the rest arranged,  
I committed with a message: "Fixed the dancing goose!"  
But the website hadn't changed. I knew I'd missed a step, caboose!

## Chorus
Repeat chorus.

## Bridge
The squirrel on the fence said, "Boy, I know your plight,"  
"You saved it to your laptop and you thought that made it right,"  
"Git is version control, GitHub's where you share,"  
"A push sends your committed work to the remote over there!"

## Final chorus
Repeat chorus.

## Outro
So I typed git push; my buddy said, "Well I'll be!"  
Then that squirrel stole my peanuts and stole the harmony!

## Educational guardrails

- **Git** does version control locally; **GitHub** hosts remote Git repositories and collaboration features.
- `git add <file>` stages chosen changes; `git commit -m "..."` commits a snapshot to the local repository; `git push` sends local commits to a configured remote branch.
- GitHub access is permissions-dependent; the song's "friends can see" assumes friends have access to the remote.
- Refrain is a memory hook, not a complete substitute for learning `git status`, branch/upstream tracking, and conflict handling.
