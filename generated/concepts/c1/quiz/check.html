Quiz

Q1

Which description best fits a value such as a string or list in Python?

  1. An object with a type, state or value, and behaviors
  2. A variable name that permanently is the object's type
  3. A value whose methods must change it in place and return nothing
  4. A mutable container, because every object can change in place
Answer and rationale

Answer: A

The first object model asks what kind of thing a value is, what it holds, and what it can do. B targets the related confusion that a name is the type. C and D target the misconception that methods must change objects in place or return nothing.

Q2

What does this call do to the original string when its result is not saved: `s.upper()`?

  1. It changes the original string in place
  2. It returns a string result and leaves the original unchanged
  3. It returns `None` after changing the original string
  4. It returns `None` and leaves the original unchanged
Answer and rationale

Answer: B

Strings are immutable. The call returns a string; the original is unchanged. A targets the misconception that a method changes the original. C targets expecting an in-place change and no useful return value. D targets expecting a method to return nothing instead of a value; assigning the string result is what makes a name refer to the returned text.

Q3

After `items.append("blue")`, which statement is correct?

  1. The list is unchanged and append returns an expanded list
  2. The list changes in place and append returns None
  3. The list changes in place and append returns the changed list
  4. The list changes in place, but append returns a new list
Answer and rationale

Answer: B

Lists are mutable sequences; append adds to the existing list and returns None. A targets expecting no mutation and an expanded return value. C targets expecting the in-place method to return the changed list. D targets expecting a new list value instead of the documented no-value return.

Q4

What kind of value does a string split method return?

  1. The original string changes in place and becomes the pieces
  2. A list of pieces
  3. Nothing is returned; split only changes the original string
  4. The original string changes in place and split returns `None`
Answer and rationale

Answer: B

Split is a string method whose result is a list; the original string is unchanged. A targets expecting a method to mutate the original. C targets expecting a method to return nothing. D combines both parts of the misconception: it expects an in-place change and a `None` result.

Q5

Which investigation sequence is the best way to explore an unfamiliar object?

  1. Use `type`, inspect names with `dir`, read focused `help`, then run a small test
  2. Use `type`, call every name from `dir` because `dir` lists only methods you must call, and skip `help`
  3. Call every name from `dir` because `dir` lists only methods you must call; errors mean the object is broken
  4. Assume every method changes the original and returns nothing
Answer and rationale

Answer: A

`type` identifies the object, `dir` helps discover names, `help` explains a type or method, and a small experiment checks a prediction. B and C target the related confusion that `dir` lists only methods you must call. D targets the misconception that every method changes the original and returns nothing.

Spaced review

R1

Given `word = "code"`, which expression produces `"o"` while `len(word)` produces `4`?

  1. `word[1]`
  2. `word[0]`
  3. `word[4]`
  4. `word[len(word)]`
Answer and rationale

Answer: A

String indexing starts at zero, so index 1 selects the second character, `o`; the length is four.

R2

If `place = "home"` and `count = 2`, what does `f"{place}: {count}"` produce?

  1. `"place: count"`
  2. `"home: 2"`
  3. `"home2"`
  4. `"{place}: {count}"`
Answer and rationale

Answer: B

An f-string evaluates the expressions inside braces and inserts their values into the surrounding text.
