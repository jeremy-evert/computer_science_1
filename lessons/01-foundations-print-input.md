# Foundations: printing, input, and execution

## Objectives

- Run a Python program in an available environment.
- Produce exact output and read user input.
- Explain the relationship between source code, execution, and observed output.

## Key content

`print`, `input`, strings versus numeric input, simple arithmetic, and submission evidence (code, output, and a short explanation).

## Historical materials

Chapter 1 assignments recur from fall 2022 onward; fall 2021 begins with “Welcome to Python” and basic arithmetic. Spring 2026 has the clearest launch sequence: Hello World, environment choice, first submission, and show-and-tell.
