# Week 09: Python object-discovery lab

Start with [00_README.md](00_README.md) for the seven-lesson roadmap, run commands, interactive help instructions, and instructor/student teaching paths.

The lab asks: **If a string is an object, can we discover how it works and then build objects of our own?** Original Wings of Fire classroom scenarios connect string inspection to a self-contained Dragon class.
