# Monday Moments — Computer Science 1

A weekly AI-fluency moment sourced from `ai_fluency/ai_i/`, scoped to where CS1 students actually are: writing their first programs. Per `docs/course-ethos.md` (2026-07-15), each Monday Moment ships in three forms: a **digest document** (a few minutes to read on their own), a **live in-class demo** capped at 15 minutes by a slide deck with a live on-screen clock, and a **podcast** (humor-forward). Each Moment is paired with a weekly quiz/practice assignment that helps students establish best practices for what it teaches.

**Engagement level for this course: AI as tutor, not typist.**

At this stage students don't yet have the judgment to spot a subtly wrong AI answer, so the moments here stay narrow and concrete:
- Using an LLM to get an explanation of an error message, not a fix.
- Asking "why" questions about syntax and control flow instead of "write this for me" questions.
- Noticing when an AI-generated answer is longer/fancier than anything covered in class — a signal to slow down, not copy it in.
- Building the habit of typing code out by hand even when a suggestion is available, because at this level the typing *is* the learning.

through a demo, then practiced through that week's Monday Moment
quiz/assignment, stays the operating shape; fifteen minutes is a hard
ceiling for the in-class demo, and the digest stays short enough to read in
a few minutes.
