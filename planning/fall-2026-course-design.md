# COMSC 1033 — Fall 2026 course design

## Course purpose

CS1 is a first programming course centered on the existing Coding Odyssey:
students turn personally meaningful ideas into small, testable Python programs.
The zyBook supplies shared vocabulary and practice, while live examples,
Odyssey gates, Monday Moments (AI Fluency), and Professional Minds retain their
existing roles. Students finish able to trace, test, and improve modest Python
programs; decompose work into functions/data; use collections and basic
classes; and disclose and validate AI-assisted work.

`zybooks-section-decisions.csv` is the executable menu: Chapters 1–9 and 11
are the normal conceptual path; labs/additional practice are selectable;
exceptions/files/inheritance/recursion are extensions; later extra-labs,
data-science, and algorithms are unused for this CS1 term.

## Semester spine and student module shape

Each Canvas/Savnac module is: **Week at a Glance** → technical/AI material →
zyBook links → active coding/Odyssey gate → Professional Minds/reflection →
assignment, rubric, and feedback. Publish that overview, links, assignment,
rubric, and accessible instructor material before student acceptance testing.
Existing plans remain the authority for dates.

## Material ZyBooks cannot replace

Coding Odyssey prompts/rubrics/feedback; AI Fluency and Professional Minds;
live tracing/debugging/code review; GitHub/pair-programming practice; and
authentic assessment of program ownership remain instructor-created.
