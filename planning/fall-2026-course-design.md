## Course purpose

CS1 is a first programming course centered on the Coding Odyssey: students
turn personally meaningful ideas into small, testable Python programs,
extended weekly through Odyssey gates and three staged checkpoints (Weeks
6, 9, 14) plus a Week 17 final submission. There is no required textbook or
external course — CS50P (Harvard's free *Introduction to Programming with
Python*) is used as a recommended, not required, concept/lecture spine
where it genuinely fits; see `docs/curriculum/recommended-resources.md`.
Students finish able to trace, test, and improve modest Python programs;
decompose work into functions/data; use collections, basic classes, and
files/persistence; and disclose and validate AI-assisted work.

## Semester spine

Each Canvas/Savnac module is: **Week at a Glance** → technical material →
recommended-resource links (optional) → active coding/Odyssey gate →
Professional Minds/reflection → assignment, rubric, and feedback.

| Week | Focus | Evidence and AI expectation |
|---|---|---|
| 1 | Success Foundations — **no programming** | Getting-to-know-you activity; no coding submission |
| 2 | Run/read/change Python; `print`/`input`; variables/expressions/types | Odyssey gate begins; inspect every AI output |
| 3 | Conversion/formatting; branching introduction | Odyssey gate; trace and format correctly |
| 4 | Branching / decisions | Active-time branching (Labor Day adjustment); test choices |
| 5 | Loops / repetition | Dry runs; verify edge cases |
| 6 | Loops consolidation | Checkpoint 1 (baby project) |
| 7 | Functions / decomposition | Decomposition and passing unit test |
| 8 | Strings / text | Text-processing practice |
| 9 | Strings continued | Checkpoint 2 (first real Odyssey pass) |
| 10 | Lists / collections | Growing-collection gate |
| 11 | Dictionaries / organized data + technical judgment | Decide/Compare #1 |
| 12 | Classes / objects round 1 | First class with state/behavior |
| 13 | Classes / objects round 2; substantial Odyssey build culminates | Interacting classes; capstone Decide/Compare #2 |
| 14 | Git / GitHub / collaboration / AI-aware workflow | Checkpoint 3 — Git-backed receipt on Week 13's real code, not a new build |
| 15 | Thanksgiving; fully asynchronous | No new technical concept; professional-pathway submission |
| 16 | Farkle / ML applied fun week | No Odyssey checkpoint; consumes the CS1 core |
| 17 | Reflection / closure | Final Debrief, Judgment Log, final reflection; no new technical material |

## Material the course owns vs. recommends vs. never requires

**Required, course-owned:** Jeremy's classes/modules/instructions; Coding
Odyssey gates/rubrics/feedback; required course reflections/professional
strands; live tracing/debugging/code review; GitHub/pair-programming
practice; authentic assessment of program ownership.

**Recommended, no-cost:** selected CS50P lecture/short/notes material where
well aligned; Python official docs as authoritative reference; surgical
links from Runestone/PY4E/Automate the Boring Stuff/etc. when they
genuinely improve one concept.

**Optional bonus practice:** carefully aligned standalone problems
(instructor-owned or selected CS50P exercises), never required, never a
base-grade penalty if skipped — see `assignments/A1-weekly-coding-practice.md`.

**Optional paid/legacy references, never required:** Deitel may be
suggested reading; ZyBooks may remain internal/legacy/optional only if
Jeremy later chooses to use it. A student must be able to complete the
required course successfully without buying either and without enrolling
in CS50P as a separate course.
