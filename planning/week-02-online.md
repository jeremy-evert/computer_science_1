# Week 2 online path — CS1

This is the explicit online companion to `planning/week-02.md`. It preserves
the same seven-beat rhythm without assuming that a face-to-face announcement
or live demonstration reaches an online student.

| Beat | Student-facing object | Purpose and path |
|---|---|---|
| Monday AI Fluency | Gather Context prompt | Read the Week 2 lens note, answer the bounded context question, and save the response with the Monday evidence. |
| Monday Local AI Lab | `lessons/week02-local-ai-00-start-here.md` through `05` | Follow the numbered route, record the readiness result, and use the Monday exit ticket. |
| Wednesday Professional Minds | Make It Stick question | Read the assigned passage, answer “How does the brain improve?”, and connect one idea to the technical work. |
| Wednesday Paired Reasoning | paired reasoning note | Compare one AI proposal with one independent check; record claim, evidence, limit, and partner response. |
| Friday Professional Minds | Mindset question | Read the assigned passage and write one revision to the week's learning approach. |
| Friday Show and Tell Reporting | A4 / A7 reflection and report | Share a small variables/formatted-output program, explain the evidence, and submit the reflection/report. |
| Sunday Reasoning Odyssey Pulse | Week 2 pulse | Submit one short claim/evidence/next-step pulse using the Week 2 Odyssey gate as the source context. |

For every beat, the online student opens this map, follows the linked source or
prompt, and submits the named evidence; no face-to-face attendance is assumed.
