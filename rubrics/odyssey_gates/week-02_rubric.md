# Odyssey Gate — Week 2 rubric: Quick Check (pass/fail) + light Build

Matches `docs/curriculum/judgment_toolkit.md` §1/§2. Two separately-graded
parts — do not average them into one score.

## Part 1 — Quick Check (pass/fail, mechanical-checkable)

| Criterion | Pass condition |
|---|---|
| Variable used | A named variable is assigned and referenced again (not a literal used once). |
| Expression present | At least one arithmetic or comparison expression computes a value from that variable. |
| World-framed output | The computed result prints as part of a sentence about the world (not a bare `print(x)`). |

**All three present → pass.** Any missing → not yet. This gate does not
average or partial-credit — see `judgment_toolkit.md`'s Quick Check design
rule (a gate is pass/fail, nuance is graded elsewhere).

**Grading route:** mechanical-checkable — a variable-assignment +
expression + print-statement pattern is detectable from the submission
without judgment calls. Suitable for a Marker LOCAL-style static/pattern
check; confirm during Marker wiring, not assumed here.

## Part 2 — Light Build (holistic, not this checklist)

| Band | What it looks like |
|---|---|
| Strong | Founding scene feels genuinely like the start of *this* world — specific numbers, a voice, more than the gate's minimum. |
| Solid | Gate passed, some real continuation beyond the minimum. |
| Minimal | Gate passed, little to no continuation. |

Matches this course's existing effort-based grading norm
(`docs/philosophy/teaching-patterns.md`) — not a point-precise rubric.

## Grading notes

- A student who passes the gate with a technically-correct but
  world-disconnected example (e.g., unrelated math with no narrative frame)
  should not pass the "world-framed output" criterion — the point is
  connecting the concept to their own project, not proving syntax in
  isolation.
- Do not penalize creative interpretations of "founding condition" — the
  four genre examples in the assignment are illustrations, not a checklist.
