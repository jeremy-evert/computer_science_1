# Reasoning Odyssey Gate — Week 9 rubric: Synthesis Checkpoint 2 (two-axis, 25 points)

Per Jeremy's 2026-08-06 decision (course_foundry prompt 026): checkpoint
weeks reuse the same two-axis rubric already defined for weekly
reinforcement (`docs/grading-model.md`, "The two-axis rubric for the
weekly reinforcement assignment") rather than a new checkpoint-specific
shape — see `rubrics/odyssey_gates/week-06_rubric.md`'s note for why this
differs from the four-axis Full Build rubric Week 14 uses (Checkpoint 3,
formerly Week 16, is retired — see `docs/grading-model.md`).

## Axis 1 — working result (15 of 25 points)

For this checkpoint, "the result" is Week 9's submit/explain/demonstrate/reflect
checkpoint itself, mapped onto the same historical effort-based ladder
`grading-model.md` describes for gate weeks: checkpoint not yet passed
(nothing meaningfully beyond Week 6)
sits around 25% of this axis; checkpoint passed with a minimal
consolidated extension 50-75%; checkpoint passed with a solid first real
synthesis pass — clearly explained, demonstrated, and reflected on — 100%.

## Axis 2 — process (10 of 25 points)

Same four dimensions as every weekly reinforcement week
(`docs/grading-model.md`): Rhetoric, Planning, Resource budgeting,
Knowledge management. 0/1/2 per dimension (8 points) + 2 points for the
whole package being organized and reusable = 10.

## Grading notes

- "Real idea, meaningfully more code" (`assignments/odyssey_gates/week-09.md`)
  is a real bar relative to Week 6's baby project; the work must show
  meaningful consolidation, not a cosmetic rename.
- The World Bible one-line log entry is required but not separately
  scored here, same convention as every other gate week.
