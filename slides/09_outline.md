# Week 9 — Objects You Use, Classes You Write

- Objects you already use: strings and lists have state and behavior.
- Strings are immutable: transformation methods such as `.strip()` and `.title()` return new strings; a list method such as `append` changes list state.
- Dot notation accesses an attribute. A data attribute stores information; a method is callable, and parentheses call it.
- Class/instance sketch: a class is a blueprint; an instance is one object made from it.
- `__init__`, state, and `self`: store two pieces of instance state and explain “this particular object.”
- Trace the `SignalBeacon` example from construction through `boost`.
