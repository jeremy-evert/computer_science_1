# Assignment template

## Purpose

Connect this task to the current chapter or project checkpoint.

## Do

1. State the problem and allowed substitutions.
2. List the required code, output/tests, and explanation.
3. Name the submission location and demonstration/reflection requirement.
4. State points, effort/working-solution criteria, and optional bonus.

## Support and integrity

Invite questions and list useful resources. Require students to explain and verify submitted code, and credit outside help or AI assistance.
