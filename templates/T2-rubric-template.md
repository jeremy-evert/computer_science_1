# Lightweight rubric template

Use the archive’s recurring non-stacking progression where appropriate:

| Evidence | Suggested mark |
|---|---:|
| Meaningful effort / partial attempt | 25 |
| One working solution or criterion | 50 |
| Two working solutions or criteria | 75 |
| Three working solutions / complete core task | 100 |
| Optional improvement, creativity, or presentation | bonus |

For projects, add separate criteria for working behavior, explanation, clarity, creativity, and reflection. Label pass/fail, bonus, and zero-point practice explicitly; historical offerings use all three.
